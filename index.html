Selected Projects

PrintEz: Printing Platform printez.app
  • Customers scan a QR code, upload a document, pay by UPI and collect the print, either at a self-service kiosk or at a partner print shop.
  • Wrote the backend in Go (Fiber) with PostgreSQL, Redis and Cloudflare R2 for file storage, and the customer site in Next.js.
  • Wrote the device software in Go, a Raspberry Pi agent for kiosks and a Windows app for print shops, both pulling jobs from the server.
  • Each job's state is saved before it reaches the printer, so a crash mid-print is caught on restart and a stuck job can move to a backup printer.
  • Updates are signed. Devices check the signature and file hash before installing, wait until nothing is printing, and hold no passwords or API keys.
  • CI builds the Raspberry Pi and Windows versions for every release. The server runs on Docker Compose behind Nginx with TLS.
